Public referrals on lotusfoundation.info submit directly over HTTPS to the lotus-referral function in the Content Creators Life Supabase project (lqmekhktucbxccfmfdzq). The function validates the same brief referral schema as the website, applies a rate limit, and returns the case number only after the write succeeds. The case tables use the lf_ prefix; rate counters live in lf_private. No staff account is created by deployment. Keep the service-role credential inside Supabase.

To deploy changes to the form schema or submission service, run npm ci, node scripts/build-referral-edge.mjs, then supabase functions deploy lotus-referral --project-ref lqmekhktucbxccfmfdzq --no-verify-jwt --use-api. Deploy the website through its existing Git integration. The function is intentionally public for intake; it provides no record retrieval operation. Preview domains do not send referrals to the production service.
